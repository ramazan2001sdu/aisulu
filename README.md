# Айсулу, моя любовь ❤️

Запуск: открой `index.html` двойным кликом (или опубликуй папку целиком, см. ниже).

## Куда класть фото
Папка `images/` (имена файлов менять не нужно, JavaScript трогать не нужно):
- `family-main.jpg` - главное фото на первом экране
- `family-final.jpg` - фото в самом конце
- `puzzle-photo.jpg` - фото для пазла
- `photo-1.jpg` ... `photo-10.jpg` - альбом (5-10 штук)
Музыка: `music/our-song.mp3`.

## Тексты
Все тексты и подписи под фото - в `index.html` (ищи нужную фразу через Ctrl+F).

## Публикация (бесплатно)
Netlify Drop (app.netlify.com/drop): перетащить папку `birthday-for-aisulu` целиком, получишь ссылку.
Или GitHub Pages / Cloudflare Pages.
